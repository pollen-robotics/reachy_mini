# Run 1: `main` @ 24f74f030 (after #1481), 2026-10-20

This is the baseline. There were 10 fresh agents, one per prompt (see `../guide-eval.workflow.js`), with no robot and no web search. All agents were Opus 5.5.

**Pattern:** every JS choice rested on the default rule, not on criteria. Both Python agents had to dig their deciding constraints out of a non-goals bullet.
