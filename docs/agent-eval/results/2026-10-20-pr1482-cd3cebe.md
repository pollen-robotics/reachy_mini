## Side effects of the PR (fixed in a follow-up commit on #1482)

## New findings

- **Head tracking overrides the return-to-rest goto.** At weight 1 it overrides every app head target, including `safelyReturnToPose`. The daemon quiets tracking before `goto_sleep`, not before `goto_target` (03, 06). Fixed in #1484.
- **Gravity compensation needs Placo**, while the daemon defaults to AnalyticalKinematics, and `set_motor_mode` gave no error (10). The daemon now replies with an error (#1484). On the test robot (Wireless, 2026-10-21), Placo is **not installed**, so hand-guiding is unavailable on stock Wireless robots.
- **The conversation template ships a broken UI** (it calls `/status` and `/validate_api_key`, which don't exist) and its tests fail out of the box: 67 of them (05).
- **Calling a localhost service from a Space** (CORS, Chrome local-network access) is undocumented (06).
- **Realtime allocator CORS evidence conflicts:** the reference README says allow-listed origins only, while preflights accepted arbitrary origins (02 vs 03).
- **No "an existing app already does this" nudge** in the docs (03).
